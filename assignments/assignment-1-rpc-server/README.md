# Assignment 1: RPC Server with Database

## Overview

This assignment implements a Remote Procedure Call (RPC) server with a database backend component.

## Components

- **server.py** - Main RPC server
- **client.py** - Client to interact with the RPC server
- **db_server.py** - Database server component
- **main.py** - Entry point for running the system
- **shared.py** - Shared utilities and constants
- **verify_system.py** - Script to verify system functionality

## Running the Assignment

```bash
# Run the main system
python main.py

# Or run individual components:
python server.py
python db_server.py
python client.py
```

## Testing

```bash
python verify_system.py
```
