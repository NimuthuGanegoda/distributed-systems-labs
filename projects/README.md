# Projects

This directory contains personal projects and experimental implementations in distributed systems.

## Structure

Each project follows this naming convention:
```
project-N-topic-name/
```

Where:
- `N` = Project number (1, 2, 3, etc.)
- `topic-name` = Brief description of the project

## Project Ideas

- Custom distributed consensus implementation
- Message queue system
- Distributed cache
- P2P network simulator
- Fault-tolerant service
- Load balancer
- Distributed file system
- And more...

## Adding New Projects

1. Create a new folder: `project-N-topic-name/`
2. Create a `README.md` with project description
3. Add all project files
4. Update this file with project info

Example:
```bash
mkdir project-1-message-queue
cd project-1-message-queue
# Add your files and README.md
```

## Standard Project Structure

```
project-N-topic-name/
├── README.md
├── requirements.txt
├── main.py
├── src/
│   └── module1.py
└── tests/
    └── test_module1.py
```
