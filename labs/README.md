# Labs

This directory contains lab exercises and practice problems for distributed systems.

## Structure

Each lab follows this naming convention:
```
lab-N-topic-name/
```

Where:
- `N` = Lab number (1, 2, 3, etc.)
- `topic-name` = Brief description of the lab

## Adding New Labs

1. Create a new folder: `lab-N-topic-name/`
2. Create a `README.md` with lab description
3. Add all lab files
4. Update this file with lab info

Example:
```bash
mkdir lab-1-socket-programming
cd lab-1-socket-programming
# Add your files and README.md
```

## Standard Lab Structure

```
lab-N-topic-name/
├── README.md
├── requirements.txt
├── main.py
└── tests/
    └── test_lab.py
```
